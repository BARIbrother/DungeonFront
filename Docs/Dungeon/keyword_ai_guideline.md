# keyword.md — 에이전트 가이드

사람이 보는 문서는 [keyword.md](keyword.md). 여기에는 적는 규칙만 둔다.

## 역할

- `keyword.md`: 키워드 목록. 기획자가 훑는 내용만.
- 이 파일: 에이전트가 `keyword.md`에 쓰거나 고칠 때.

`00-dungeon.md`와 충돌하면 던전 기획서가 우선. 다만 **부적 · 스킬석**은 아래 사전 지식이 더 최신이다.

## keyword.md에 넣지 말 것

- 쓰는 법, 칸 설명, 「한 줄이면 충분하다」 같은 지시
- 확정 아님을 반복하는 문장, 채택이 아님, 시드, 대화 시작용
- 키워드 설계 철학 불릿 (이름만으로 구분, 스킬·장비 공용 등)
- 이 가이드로의 링크

## 항목 형식

`keyword.md` 표 (칸은 파일에 있는 것만 쓴다. 현재 이름 · 효과):

| 칸 | 내용 |
|----|------|
| 이름 | 플레이어가 볼 짧은 말 |
| 효과 | 무엇이 일어나는지. 어디에 붙는지도 여기에 적는다 |

표에 행을 추가한다. 분류 섹션은 사용자가 나누라고 하거나, 대화에서 나온 묶음이 있을 때만 만든다.

미리 채우지 않는다. 이번 대화에서 나온 키워드만 적는다.

## 사전 지식

- 던전은 4인 파티. 플레이어가 조종하는 건 필드에 나와 있는 **1명**. 원신 · 명조와 같음.
- 캐릭터 간 상호작용 키워드부터 쌓는 중.
- **부적**: 캐릭터마다. 키워드가 있는 서브 스킬을 **여러 개** 달 수 있다. 제일 먼저 단 것부터 **순서대로** 사용.
- **우클릭**: 현재 캐릭터가 장착한 스킬석을 **처음부터 차례대로** 시전. 다른 멤버 부적은 안 씀.
- **Q/E**: 수동 교체. 부적 스킬석 `교체`와 별개. 비상용이기도 함.
- **메인 스킬 쿨타임**: 현재 조종 중이 아니어도 돈다.
- **스킬석**: 스킬과 **일대일**. 유저가 부적의 스킬석 슬롯에 자유롭게 장착·해제. `keyword.md` 용어란이 설명 정본.
- `교체` 스킬석을 빼면 그 칸에 다른 스킬석(버프 등)을 넣을 수 있다. **고점**은 Q/E 손컨 + 부적은 버프 등, **저점**은 우클릭만으로 `교체`가 포함된 매크로.
- 부적마다 슬롯이 다름: **칸 수**(2칸, 3칸 등)와 **넣을 수 있는 스킬석 유형**. 유형 이름 목록은 아직 없음. 지어내지 않는다.
- 던전 들어가기 전에 부적 사이클을 짜고 입장.
- 스킬석에 **태그**가 붙는다. 지금은 `실패 시 중단`, `실패 시 다음 스킬 시전`만. 더 만들지 않는다.
- `스킬 사용`은 메인 스킬이 쿨이면 **실패**할 수 있다. 그때 그 스킬석 태그가 시퀀스를 멈출지, 다음 칸을 칠지 정한다.
- 부적에 붙는 키워드는 효과 칸에 `부적 스킬석`으로 적는다. 태그는 **스킬석 태그** 섹션.

## 적을 때

- 확정처럼 쓰지 않는다. 목록은 브레인스토밍이다.
- 기존 인챈트(불·물·바람·땅·전기·얼음·독·순수)와 같은 이름을 쓸지는 미정. 합치지 말고 메모에만 적는다.
- 상태이상은 던전 기획서에서 `[미정]`.
- 스킬석 하나하나는 단순. 부적 전체의 순서가 조합이다.
- 같은 키워드가 스킬과 장비 양쪽에 붙어도 된다.
- 문장은 짧게. 메타 설명·강조 남발 없이 효과만.

## 전투 골격 (키워드가 붙는 곳)

이동 + 좌클릭 공격 · 스페이스 주 스킬 · 우클릭 = 현재 캐릭터 부적 스킬석을 처음부터 차례로 · 실패 시 중단/다음 · Q/E 수동 교체(비상·고점) · 메인 스킬 쿨은 대기 중에도 진행 · 필드 1인 / 파티 4.
