# 키워드

## 용어
| 이름 | 설명 |
| 현재 캐릭터 | 4명의 파티 중 현재 플레이어가 조종 중인 캐릭터 |
| 스킬석 | 부적에 장식할 수 있는 아이템. 전투 중 우클릭 시 현재 캐릭터가 장착한 스킬석들의 스킬이 처음부터 차례대로 시전된다. |
| 메인 스킬 쿨타임 | 현재 조종 중이 아니어도 돈다. |

## 캐릭터 간 상호작용

| 이름 | 효과 |
|------|------|
| 교체 | 부적 스킬석. 파티의 다른 캐릭터로 바꿈 (3번, 다음 등) |
| 스킬 사용 | 부적 스킬석. 현재 캐릭터의 메인 스킬을 사용한다. |
| 공격력 증가 | 부적 스킬석. 현재 캐릭터에게 특정 수치만큼 공격력을 증가시킨다 |
| 방어력 증가 | 공격력 증가와 동일 |
| 속성 저항력 증가 | 공격력 증가와 동일 |

## 스킬석 태그

| 이름 | 효과 |
|------|------|
| 실패 시 중단 | 이 스킬석 시전 실패 시 이후 스킬석을 시전하지 않음. [2번 교체] → [스킬 사용] → [3번 교체]에서 2번 스킬이 쿨이면 2번에 남음 |
| 실패 시 다음 스킬 시전 | 실패해도 다음 스킬석을 시전. 같은 예에서 3번으로 교체 |
