# equipments.md — 에이전트 가이드

사람이 보는 문서는 [equipments.md](equipments.md). 여기에는 적는 규칙만 둔다.

## 역할

- `equipments.md`: 장비 효과 목록. 기획자가 훑는 내용만.
- 이 파일: 에이전트가 `equipments.md`에 쓰거나 고칠 때.

`00-dungeon.md`와 충돌하면 던전 기획서가 우선. 키워드 이름은 [keyword.md](keyword.md)와 맞춘다. 같은 이름을 장비 쪽에서 다시 정의하지 않는다. 장비에 붙을 때 달라지는 점만 적는다.

## equipments.md에 넣지 말 것

- 쓰는 법, 칸 설명, 「한 줄이면 충분하다」 같은 지시
- 확정 아님을 반복하는 문장, 채택이 아님, 시드, 대화 시작용
- 장비 설계 철학 불릿 (수치+부가, 장비 시험이 본전 등)
- 이 가이드로의 링크
- 아이템 ID·레시피·제작 경로 (공장 시트 영역)

## 항목 형식

`equipments.md` 표. 칸은 파일에 있는 것만 쓴다. 처음 행을 넣을 때 아래 칸으로 표를 만든다.

| 칸 | 내용 |
|----|------|
| 이름 | 플레이어가 볼 짧은 말 |
| 부위 | 무기 · 투구 · 흉갑 · 각반 · 부츠 · 부적 · 공용. 슬롯이 미정이면 공용 |
| 효과 | 무엇이 일어나는지. 수치면 수치, 부가면 부가. 어디에 붙는지도 여기 |

표에 행을 추가한다. 분류 섹션은 사용자가 나누라고 하거나, 대화에서 나온 묶음이 있을 때만 만든다.

미리 채우지 않는다. 이번 대화에서 나온 효과만 적는다.

## 사전 지식

- 던전은 4인 파티. 플레이어가 조종하는 건 필드에 나와 있는 **1명**. 원신 · 명조와 같음.
- 공장에서 만든 장비를 들고 입장. 캐릭터에게 장착. 다른 멤버에게 주려면 **벗어야** 함.
- 장비 = **수치** + **부가 효과**. 부적 = 우클릭 서브 스킬.
- 들고 가는 것: **지금은 무기**(와 입고 있는 방어구) + **부적**. 슬롯 수는 미정.
- 아트 기준 방어구 부위: 투구 · 흉갑 · 각반 · 부츠.
- 플레이어 판타지: **장비 시험**과 **파밍**이 둘 다 본전.

## 적을 때

- 확정처럼 쓰지 않는다. 목록은 브레인스토밍이다.
- 슬롯 개수·세트 보너스·내구를 단정하지 않는다. 나오면 메모만.
- 소재(철·흑강·백강·진강 등)가 효과를 가른다고 쓰지 않는다. 대화에서 나오기 전엔 행을 만들지 않는다.
- 상태이상은 던전 기획서에서 `[미정]`.
- 부적은 주 스킬보다 단순하게.
- 문장은 짧게. 메타 설명·강조 남발 없이 효과만.

## 전투 골격 (효과가 붙는 곳)

이동 + 좌클릭 공격 · 스페이스 주 스킬 · 우클릭 부적 · Q/E 교체 · 필드 1인 / 파티 4 (원신 · 명조).
