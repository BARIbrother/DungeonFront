## 채우는 규칙

- **확정만** 본문에 적는다. 미정은 `[미정]`.
- `redesign-direction.md`에서 이미 정한 것은 **§0**에 두고 다시 묻지 않는다.
- 세계관(이름·주인·지명)과 플레이 룰은 나눈다. 여기는 **플레이어가 던전에서 하는 일**.

## 0. 이미 확정된 방향

`redesign-direction.md`에서 가져온 것. 뒤집지 않는 한 재질문하지 않음.

| 항목 | 내용 |
|------|------|
| 시점·장르 | 공장과 같은 **탑다운 액션** |
| 세션 길이 | 한 번의 탐사 ≈ **5~10분** |
| 호흡 | 한 번의 탐사 = 한 세션. 들어갔다 나오는 구간이 쉼표 |
| 공장 | 탐사 중 **정지** (백그라운드 틱·고장 누적 없음). 귀환 후 재가동 |

| 메인 스토리 | 던전 층계·명예·세계 상태와 연동되는 **진행 축** |

## 3. 세션 흐름

공장 ↔ 던전 전환부터 귀환까지.

| 단계 | 플레이어가 하는 일 | 비고 |
|------|---------------------|------|
| 출발 준비 | **테마·목표 층 선택** | 해금된 층만 |
| 입장 | 고른 **그 층만** 입장 | |
| 탐사 중 | 한 방에서 **스폰·층 목표**에 맞춰 전투. 목표는 층마다 다름 (보스 포함일 수도) | |
| 클리어 / 중도 귀환 | **웨이브·층 목표 달성** 또는 **언제든 자진 귀환** | 층 클리어 시 다음 층 해금(순차). 자진 귀환은 루팅 **일부만** |
| 실패·사망 | **파티 전멸** (4명 모두 쓰러짐) | 루팅 50% 손실(초기) |
| 귀환 후 (공장) | 공장 **재가동**. 루팅 정산(클리어=전부 / 자진=일부 / 실패=50%부터) | 게임 오버 없음 |

| 항목 | 내용 |
|------|------|
| 중도 귀환 | **언제든 가능**. 이번 루팅은 **일부만** 가져감. 세율은 실패(초기 50%)와 **같거나 더 낮음** — 숫자는 **나중에** |
| 목표 (한 세션의 성공 조건) | **선택한 층 클리어**. 명예는 그 층 **최초 클리어만** |
| 시간 제한 | **없음**. 5~10분은 **맵 규모로 맞추는 체감**일 뿐. 강제 종료 없음 |
| 재입장 타이밍 | 해금된 층은 **언제든** 다시 선택 가능 (파밍) |

## 6. 전투

| 항목 | 내용 |
|------|------|
| 조작 | **이동** + **좌클릭 공격**. **스페이스** 주 스킬. **우클릭** 서브 스킬(부적). **Q / E** 캐릭터 교체 |
| 파티 | **1파티 4인**. **필드에는 한 명만** (교체한 캐릭터가 나와서 싸움) |
| 파티 구성 | 주인공이 **모험가를 고용**해 **4슬롯**에 편성. **대장장이(주인공)도 슬롯에 넣을 수 있음** |
| 체력 | **캐릭터마다** 체력. 쓰러지면 **그 캐릭터만 아웃** → 다른 멤버로 교체. **4명 전부 쓰러지면 실패** |
| 직업 | 캐릭터에 **직업**이 있음. **주 스킬은 직업이 정함**. **전직 트리**를 타면 그 스킬에 **부가 효과**가 붙음 |
| 직업 목록·전직 | **나중에 기입** |
| 피해 공식 | `[미정]` |
| 회피·가드 | **조작으로는 없음**. 이동으로 피하고, 스킬·교체로 대응. **부적 서브**로 가드 상태 등은 가능 |
| 스킬·마법 | **스페이스** = 직업 주 스킬 (전직으로 부가). **우클릭** = **부적** 서브 스킬. 주 스킬보다 단순, **전투 보조** |
| 장비 효과 | 장비 = **수치** + **부가 효과**. **부적** = 우클릭 서브 스킬. 예: 1번 캐릭터로 교체 / 다음 캐릭터로 교체 / 공격 가드 상태 부여 |
| 상태이상 | `[미정]` |
| 난이도 곡선 | `[미정]` |

### 고용

| 항목 | 내용 |
|------|------|
| 구하는 방법 | **기본은 골드 고용**. **일부 캐릭터는 스토리로만 해금** |
| 비용 | `[미정]` |
| 로스터 규모 | **고용 풀은 여럿**. 그중 **4명만 출전**. 풀 상한은 **나중에** |
| 장비 지급 | 공장 제작 무기·방어구·부적. **캐릭터에게 장착**. 다른 멤버에게 주려면 **벗어야** 함 |

### 캐릭터 육성

| 항목 | 내용 |
|------|------|
| 성장 축 | **레벨(스탯)** + **전직 트리** + **장비** |
| 레벨 효과 | **기초 스탯만** (체력·공격). 스킬 변화는 **전직 트리** |
| 전직 트리 | 직업 주 스킬에 **부가 효과**. **레벨이 노드를 염**. 찍는 비용은 **없음 또는 소량 골드** |
| 캐릭터별 저장 | **레벨·전직·장비 유지**. **해고 없음** — 로스터에서 출전 4에 안 넣을 뿐 |
| 주인공(대장장이) | **모험가와 같은** 레벨·직업·전직. 출전 XP는 4슬롯에 넣었을 때만. **XP 기계로는 언제든** |
| 성장 자원 | 던전 XP(출전 4인 동일) + **공장 XP 기계(재료)** + 장비. 전직은 레벨 게이트 |
### XP 기계

| 항목 | 내용 |
|------|------|
| 역할 | 재료를 넣고 **지정한 캐릭터**의 XP를 올림. 출전 여부와 무관 |
| 가동 | 캐릭터를 기계에 **넣음**. 공장이 도는 동안 그 캐릭터가 **훈련**. 탐사 중 공장 정지 → 훈련도 정지 |
| 지정 | 기계 **1대 = 캐릭터 1명**. 여러 대 놓으면 **여러 명 동시 훈련**. 넣은 동안 **출전 불가** |
| 재료·레시피 | **나중에 기입** |
| 테크·해금 | **초반부터 있음** |
| 수동→자동 | **처음엔 수동**. 자동화는 **테크 나중에** |

| 항목 | 내용 |
|------|------|
| 실패 조건 | **파티 전멸** (4명 모두 쓰러짐). 타이머 실패 없음 |
| 사망 연출 | `[미정]` |
| 「이번 루팅」의 범위 | 이번 탐사에서 **얻은** 골드·희귀 자원 등. **들고 간 장비·부적은 제외** |
| 50% 계산 | `[미정]` (개수 반올림, 종류별, 랜덤 슬롯) |
| 자진 귀환 세율 | **실패보다 같거나 낮음**. 숫자는 **나중에** |

## 14. 다음에 채울 순서

아래 순서로 질문한다. 한 항목이 막히면 그 전제를 먼저.

1. ~~던전 구성~~ — 6테마 × 테마별 순차 층계, 스토리 게이트, 층 선택 입장, 층 수는 시트에서
2. ~~한 줄 · 판타지~~ — 장비 시험 + 파밍이 둘 다 본전. 남은 것: 핵심 재미·참고 게임·하지 않을 것
3. ~~세션 흐름~~ — 층 선택 입장, 자진 귀환(루팅 일부), 타이머 없음. 남은 것: 탐사 중 행동(맵·전투), 실패 상세, 자진 세율 수치
4. **맵 · 레벨** — 테마당 방 1개 + 테마 기믹. 남은 것: 규모, 시야, 파괴·환경
5. **로드아웃** — 지금은 무기(+입고 있는 방어구). 슬롯·소모품·인벤·내구·입장 비용은 나중에
6. ~~전투~~ — 골격 확정. 직업 목록·전직·피해 공식·상태이상은 나중에
7. **몬스터 · 보스** — 웨이브, 층 목표에 따라 보스. 남은 것: 역할 분류, 목록, AI
8. **보상** — 처치+클리어 골드·희귀. 종류·명예 수치는 나중에
9. **실패 · 루팅 손실** — 루팅만 깎임, 장비 유지. 세율·계산·완화 업그레이드는 나중에
10. ~~고용 모험가~~ — 골드 고용 + 스토리 해금, 풀에서 4명 출전. 비용·풀 상한은 나중에
11. **첫 던전 시트** — 뒷산: 기믹 없음. 층 수·몹·보스는 나중에
12. **튜토리얼** — 스토리가 뒷산을 연 뒤 루프 전체. 첫 탐사는 전멸해도 실패 아님. 남은 것: 첫 층 구성
13. ~~캐릭터 육성~~ — 레벨(체력·공격)+전직(레벨 게이트)+장비 장착, 출전 4인 동일 XP, XP 기계(초반 수동, 1대=1명), 해고 없음. 남은 것: 재료·직업 목록·레벨 캡
