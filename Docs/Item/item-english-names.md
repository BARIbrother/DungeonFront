## Notes

- `철 주괴` / `철주괴` and similar spacing variants are the same item (`iron_bar`).
- Icon map historically used `iron` for 철 주괴; runtime SO id is `iron_bar` (existing assets).
- `상급 몬스터 마나 점수` / `하급·중급 몬스터 마나 정수`는 표시명을 하급·중급·상급 마나 정수로 바꾼다. itemId는 그대로다.
- 마나 함량: 하급 10, 중급 50, 상급 100, 던전의 주인의 정수 500. 레시피는 느슨한 `mana` 대신 이 정수를 쓴다.
- `xN` / `x N` means quantity N of that item (not a distinct item).

## Enchantment types

Stored on `Item` as `enchantments` (`List<Enchantment>` = 속성 + 형태).
Max count is `ItemDefinition.enchantmentSlotCount`.
Different enchantment sets do not stack (`Item.CanStackWith`).

## Recipe level requirements

Level is on runtime `Item.level` (not `ItemDefinition`). Recipe inputs store `Item` with the
minimum required level; machines accept the same definition at that level or higher
(`Item.SatisfiesRecipeRequirement`).

| recipeId | slot | required |
|----------|------|----------|
| `craft_dark_magic_core` | `mana_core`, `blackstone_ingot` | lv2+ |
| `craft_light_magic_core` | `mana_core`, `whitestone_ingot` | lv2+ |
| `alloy_greysteel_ingot` | `iron_bar`, `blackstone_ingot`, `whitestone_ingot` | lv2+ |
| `craft_greatsword_blade` | `iron_plate`, `iron_rod` | lv3+ |
| `craft_ritual_iron_greatsword` | `iron_rod`, `iron_bar` | lv3+ |

## recipeTime (tick) design

1초 = 10틱. 진행도 단위는 10배라 T1 `workSpeed`=10, 제련 `recipeTime`=100이면 예전과 같이 1초다. For 1:1 item chains, lower step is half the upper step so balanced factories land near **1 lower : 2 upper**.

- Smelt / basic refine: **100**
- Parts from bars (plate/rod): **200**
- Iron equipment: **400**
- Alloy plate/rod: **400**; alloy gear: **800**
- Greysteel plate/rod: **800**; greysteel gear: **1600**
- Ritual / altar endgame: **1600–3200**
