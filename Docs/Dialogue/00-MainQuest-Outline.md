# 메인 퀘스트 스토리 대사 아웃라인

> 사이드/상시 의뢰는 **소개 문구(`content`)만** 사용. 스토리 대사는 **메인 수락(및 아래 표의 키 비트)** 만.  
> **이 폴더의 Q번호 = 스토리 진행 순.** `questline.json`의 id는 제작 순이라 여기와 1:1이 아니다.  
> 파일명: `main-Q###-{accept|production|settle|ending}.md`

## 대사 출현 시점

일차 페이즈: **준비(Prepare) → 생산(Production) → 결산(Settlement)**


| 파일                                                   | 페이즈 | 타이밍                | 직후                                       |
| ---------------------------------------------------- | --- | ------------------ | ---------------------------------------- |
| `main-Q001-accept`                                   | 준비  | 준비 단계 시작 직후        | 플레이 계속 (의뢰 수락)                           |
| `main-Q001-production`                               | 생산  | 파일 내 게이트 튜토        | *(파일 괄호 연출)*                             |
| `main-Q001-settle`                                   | 결산  | 결산 시작 후, 스토리 대사 재생 | 대사 종료 후 **결산 판넬** 표시                     |
| `main-Q002-settle`                                   | 결산  | 결산 시작 후, 스토리 대사 재생 | 대사 종료 후 **결산 판넬** 표시                     |
| `main-Q010-ending`                                   | 결산  | 결산 시작 후, 스토리 대사 재생 | 대사 종료 후 **결산 판넬** 표시 *(클리어 후 크레딧 등은 후속)* |
| `main-Q002-accept` ~ `main-Q010-accept` 등 그 외 accept | 준비  | 준비 단계 시작 직후        | 해당 비트 처리 후 준비 단계 진행                      |


### 규칙 요약

1. **Q001-accept** — 준비 단계가 시작되면 스토리 대사를 재생한다.
2. **결산 스토리 대사** (`Q001-settle` · `Q002-settle` · `Q010-ending`) — **결산이 시작된 뒤** 스토리 대사를 재생하고, **대사가 끝난 다음에 결산 판넬을 띄운다.**
3. **그 외 accept** (Q002~Q010) — 해당 비트가 뜨는 날, 준비 단계가 시작되면 스토리 대사를 재생한다.
4. 같은 준비/결산 단계에 스토리 대사가 여러 개면, 진행 축 표 순서를 따른다.
5. **Q001-production** — 시점은 파일 본문 괄호(행동 게이트)를 따른다.

## 일차 메모 (초안)

- 1일차: Q001-accept(준비 시작) → production(생산) → settle(결산 시작 → 스토리 대사 → 결산 판넬). 이브 「모레 다시」
- Q002: accept는 준비 시작 직후 / settle은 골드 납품이 반영된 날, **결산 시작 후 스토리 대사 → 그다음 결산 판넬**
- 3일차 전후: Q002 → Q003. 스토리 only면 압축 가능
- Q005(알렉)은 합금 시험 다음 **기술 해금 비트**
- Q008(의식)은 구조물 시험 다음 레이 에피소드
- Q010-ending: 최종 과제 클리어 날, **결산 시작 후 스토리 대사 → 그다음 결산 판넬**. B(해럴드)가 같은 결산에 이어지는지, 별도 일차인지는 연출 재량
