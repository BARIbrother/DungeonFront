# 우리가 정확히 완성해야 하는 것

## 목표

플레이어가 대장간 면허 시험을 통과하는 2D 공장 운영 게임을 **Factory 씬 하나에서 처음부터 하루를 끝까지** 플레이할 수 있어야 한다.

```
대사/튜토리얼 → 준비 → 생산 → 결산 → 다음 날
```

## 필수 플레이 흐름

### 1. 시작과 대사

- Day 1, Prepare에서 시작한다.
- `001E00001` 오프닝 대사 후 `001E00002` 첫 의뢰 안내가 표시된다.
- 대사 중 게임은 멈추고, 닫으면 다시 진행한다.

### 2. 준비(Prepare)

- 의뢰를 최대 3개 수락한다.
- 시작 기계: 채굴기, 용광로, 수동 제작대, 창고를 실제 `PlayerInventory`에서 받는다.
- 기계를 배치하고 레시피를 정한다.
- 골드로 구매하고, 명성 조건이 되면 기계를 해금한다.
- 생산 시작 버튼을 누른다.

### 3. 생산(Production)

- 기계가 재료를 가공해 인벤토리에 생산품을 쌓는다.
- 첫날 핵심 체인: 철 광석 → 철 → 철 판/철 막대.
- 생산 종료 시 완성품이 인벤토리로 모이고 요약을 보여 준다.

### 4. 결산(Settlement)

- 수락 의뢰 카드에 `보유 n / 요구 m`, 납기, 보상이 표시된다.
- 재료가 전부 있을 때만 한 번에 납품한다. 부분 납품은 불가하다.
- 일반 의뢰는 골드·명성을 지급하고, 필수 의뢰 미납은 게임오버다.
- 상시 의뢰는 수락 없이 배수를 정해 반복 납품한다.
- 다음 날로 넘어간다.

## 이번 작업에서 구현/보정한 항목

- 대사 UI, 일시정지, ESC 설정 메뉴, 저장/불러오기
- 퀘스트 카드 보유/요구 수량과 HUD 실제 의뢰 수
- 상시 의뢰 배수 납품 UI
- 게임오버 오버레이와 새 게임 시작
- 시작 시 실제 PlayerInventory에 기계 지급하도록 연결
- TMP 한글 폰트 런타임 보정

## 아직 기획 또는 데이터가 필요한 항목

1. **아이템 아이콘**: 요청에 따라 보류. 아이템별 스타일·해상도·목록을 정한 뒤 생성/연결한다.
2. **후반 아이템/레시피**: 퀘스트 ID는 47개지만 요구 itemId 62종 중 대부분의 실제 ItemDefinition·레시피가 없다. 후반 의뢰를 정상 클리어하려면 데이터 제작이 필요하다.
3. **스토리 대사 본문/초상**: 현재는 MVP용 짧은 대사와 이니셜 placeholder다. `Docs/Dialogue`의 정식 대사와 초상 에셋을 연결해야 한다.
4. **월드 튜토리얼 강조**: 튜토리얼 패널은 있으나 기계·버튼을 가리키는 화살표/카메라 연출은 별도 작업이다.
5. **월드 배치 저장**: 현재 저장은 세션·아이템·의뢰 중심이며, 맵 위 기계 배치와 생산 중 상태는 저장하지 않는다.
