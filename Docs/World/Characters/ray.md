| 본명 | 빙염룡 **블레이메르** (인류 시대 잔존 용 **3개체** 중 하나 → 세간은 사망으로 봄) |

| 과거 | 설산 거주. **50년 전** 마나핵 폭주로 전 세계 빙하기 직전 → **해럴드**(초대 용사)에게 토벌. 마력핵 상실 후 깊은 골짜기로 떨어져 **사망 취급**(세간상 용은 2체만 남음). 실제로는 생존. 인간으로 폴리모프해 거지꼴로 떠돌다 주인공 대장간에 도착 |
| 배경 (대장간) | 주인공에게 돈을 구걸하며 등장. 식량 거덜 낸 뒤 「갚는다」며 얹혀살며 공장 도움 |
| 능력 | 얼음·화염에 능숙, 전반적으로 다재다능 마법사 |
| 성격 | 반말. 털털함 / 생존 본능 결여. 만사 귀찮음. **모든 존재에게 반말** |
| 외형 | 인간 기준: 하늘색 장발 곱슬. 로브. 무기력·나른한 인상 |

| 상대 | 내용 |
|------|------|
| 주인공 | 얹혀살이·공장 조력 → 엔딩: **적당히 티키타카 되는 친구**. 주인공은 레이 정체를 **모름** (물 심부름으로 자리 비움) |
| 이브 | **서로 별로 관심 없음.** 레이 기준으로: 가끔 찾아오는 목석 같은 여자 |
