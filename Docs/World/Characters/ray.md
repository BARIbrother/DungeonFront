# 레이

> 상태: **주요 항목 채움** — 대화로 확정.

| 항목 | 내용 |
|------|------|
| 이름 | 레이 (통칭) |
| 본명 | 빙염룡 **블레이메르** (인류 시대 잔존 용 **3개체** 중 하나 → 세간은 사망으로 봄) |
| npcId | `ray` |
| 역할 | 대장간 직원 · 마법 테크 안내 |
| 최초 등장 | 일반 **3일차** / 스토리 only **1일차** |
| 나이대 | 외형 **20대 초반**. 실제로는 **수십만 살 용** |
| 과거 | 설산 거주. 용 중에서도 **손에 꼽히게 착함** → 인간 피해를 피하려 힘을 **최대한 억제**. 그 역효과로 **마나핵**에 힘이 과적·**폭주**(본인도 감당 불가) → 전 세계 빙하기 직전 → **해럴드**에게 토벌. 해럴드가 꿰뚫은 「심장」은 사실 **마나핵**. 상실 후 골짜기로 떨어져 **사망 취급**. 실제 생존. 인간 폴리모프 후 거지꼴로 떠돌다 주인공 대장간에 도착. 폭주 진상은 **본인만** 앎 (**해럴드도 모름**) |
| 배경 (대장간) | 주인공에게 돈을 구걸하며 등장. 식량 거덜 낸 뒤 「갚는다」며 얹혀살며 공장 도움 |
| 능력 | 얼음·화염에 능숙, 전반적으로 다재다능 마법사. **마나핵(심장으로 알려진 것)** 상실 후 현재 주문력은 **S급 마법사** 수준 |
| 모험가 | 등록·급수 **없음** (일반 마법사와 달리 협회 미소속) |
| 성격 | 반말. 털털함 / 생존 본능 결여. 만사 귀찮음. **모든 존재에게 반말** |
| 외형 | 인간 기준: 하늘색 장발 곱슬. 로브. 무기력·나른한 인상 |

## 관계

| 상대 | 내용 |
|------|------|
| 주인공 | 얹혀살이·공장 조력 → 엔딩: **적당히 티키타카 되는 친구**. 주인공은 레이 정체를 **모름** (물 심부름으로 자리 비움) |
| 이브 | **서로 별로 관심 없음.** 레이 기준으로: 가끔 찾아오는 목석 같은 여자 |
| 해럴드 (초대 용사) | 과거 토벌 상대. 엔딩: 단둘이 남아 **서로 정체를 눈치챔**. 해럴드가 「**블레이메르**」라 부름 → MVP 엔딩. 폭주 진상은 **모름** |
