# 전 주인 (친척)

> 상태: **설정 확정 (최소)** — **게임 내 등장 없음**.

| 항목 | 내용 |
|------|------|
| 이름 | **없음** (미등장·불명) |
| 주인공과의 관계 | **7촌** 정도 친척 |
| 역할 | **수제 강철**을 은퇴·양도해, 주인공이 대장간을 시작할 수 있게 함 |
| 등장 | **게임 내 등장 없음** |
| 은퇴 이유 | **고령** |

## 개연성 (주인공이 「초보 대장장이」인 이유)

| 항목 | 내용 |
|------|------|
| 재능 | 주인공은 **공장 쪽 뛰어난 재능**을 이미 가지고 있었음 |
| 제약 | **대장간을 살 돈이 없어** 모험가로 일함 |
| 전 주인의 역할 | **고령** 은퇴로 **빈 대장간(수제 강철)**이 생김 → 주인공이 물려받아 개업. 실력은 있으나 **면허·정식 개업 경험은 없는 초보**로 시작 |
