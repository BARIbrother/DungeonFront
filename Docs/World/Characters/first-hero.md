## 과거·행적

| 항목 | 내용 |
|------|------|
| 50년 전 | 블레이메르(빙염룡)의 마나핵 폭주로 전 세계 빙하기 직전 → **토벌**. 마력핵을 잃게 함 |
| 용사 칭호 | 이 공로로 **「용사」라는 칭호 자체가 생김**. 이후 세계에 지대한 공헌을 한 자에게 수여. **현재까지 해럴드 포함 9명** |
| 현재 | 세계일주 여행 중 |
| 엔딩 | **수제 강철**에 첫 방문. 주인공은 전설 속 인물에 흥분. 해럴드가 주인공에게 **물 좀 가져다 달라**고 함 → 해럴드·레이만 남음 → **서로 정체를 눈치챔** → 해럴드가 「**블레이메르**」라고 부르는 것이 **MVP 엔딩** |

| 상대 | 내용 |

| 주인공 | 엔딩에서 **처음 만남**. 주인공은 흥분. 해럴드는 물을 심부름시킴 (정체 대화 자리 비우기) |
