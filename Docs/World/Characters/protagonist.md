# 주인공

> 상태: **주요 항목 채움** — 대화로 확정.

| 항목 | 내용 |
|------|------|
| 이름 | 유저 입력. **디폴트: 비트** |
| 성별 | 남 |
| 호칭 (이브) | 사무적 — 시험자, 귀하, 본명+님 등 |
| 호칭 (레이) | 너, 야, 본명을 직접 부름 등 |
| 나이대 | 20대 초반 |
| npcId | (플레이어) |
| 한 줄 | 「공장이 너무 좋아」 |
| 배경 | **공장 쪽 뛰어난 재능**이 있었으나 **대장간을 살 돈이 없어** 모험가로 일함. 모험가 시절 **언젠가 S급**까지 갈 인재로 **고평가**. 다만 **급수를 받기 전에** 대장장이로 전향·은퇴. **7촌** 친척 대장장이 은퇴로 **수제 강철**을 물려받음. 실력은 있으나 면허·정식 개업은 초보. |
| 성격 | 공장 집착이 광기에 가까움. 보이면 공정부터 머릿속에 짬. 공장으로 못 만드는 것엔 관심 적음. |
| 오프닝 상태 | 정식 **대장장이 면허 없음**. 모험가 훈련소 **임시 등록증**만 보유. 모험가 **급수 없음**(전향·은퇴가 급수 부여 전) |
| MVP 엔딩 | **동** 등급 대장장이 면허 취득 |
| 의뢰 | MVP에서 **상시**(협회 단체)·**일반**(직접) **둘 다** 수주. 면허 전 = **실기 중**이라 허용 |
| 외형 | 머리: 갈색 단발. 체형: 키 크고 살짝 근육질. 복장: 대장장이 앞치마·장갑·고글. 인상: 순해 보이나 공장 관련이면 집착 |
| 성장·변화 | 대장장이 능력은 **처음부터 완성형**. 변화의 축은 실력보다 **사람** — 협회 시험을 거치며 이브·레이와 친밀해짐 |

## 관계

| 상대 | 내용 |
|------|------|
| 이브 | 1일차부터 실기 시험·평가. 엔딩: **여전히 사무적이지만 신뢰** |
| 레이 | 얹혀살며 공장 도움 → 엔딩: **적당히 티키타카 되는 친구**. 정체(용)는 **모름** (엔딩에 물 심부름으로 자리 비움. 해럴드가 「블레이메르」라 부르는 장면이 MVP 엔딩) |
| 전 주인 | **7촌** 친척. 이름 없음·**게임 미등장**. 대장간 양도로 「능력 있는데 초보」개연성 |
