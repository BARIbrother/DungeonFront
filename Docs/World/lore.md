# lore — 세계관의 넓이·깊이

> **역할**: 플레이에 필수는 아니지만, 세계가 **넓고 깊게** 느껴지게 하는 배경·전설·사회 현상·문화.  
> **채우는 방식**: 비어 있는 것을 질문 → 답으로 확정 → 이 파일(또는 해당 World 파일)에 반영.  
> 인물 본체: [Characters/](Characters/00-index.md) · 용사: [Characters/hero.md](Characters/hero.md) · 개요: [01-world.md](01-world.md)

## 던전 · 모험가 육성

| 항목 | 내용 |
|------|------|
| 모험가 | 보통 **자기 급수에 맞는 던전**을 찾아다니며 실력을 쌓음 |
| 협회 방침 | 자연 생성 던전을 **전부 찾아 없애려 하지 않음** |
| 제거 대상 | 인간에게 **큰 위협**이 되는 신규·위험 던전 — 제거에는 **인력**이 필요 |
| 유지 이유 | 잘 관리하면 큰 위협이 안 되는 던전이 많아, **모험가 육성** 용도로 남김 |
| 예 | **뒷산 동굴**(모르즈 동굴) — 입문·급수에 맞는 육성용 |

## 용에 대한 인식

| 항목 | 내용 |
|------|------|
| 세간 | **신 취급** |
| 공포 | 「용을 두려워한다」는 **개념 자체가 없음** |
| 태도 | 용의 행동은 **운명**으로 받아들임. **범접할 수 없는** 경지 |
| 여신교 | **충돌 없음** — 용=살아 있는 신 · 여신=우주 법칙·의지 |
| 해럴드 | 블레이메르 **토벌**은 세간에 **신을 벤 기적**으로 인식 |
| 폭주 원인 | 용 중 **손에 꼽히게 착함**. 인간 피해를 피하려 설산에서 힘을 **최대한 억제** → 마나핵에 힘 **과적** → 본인도 감당 불가해 폭주. **본인만** 앎 (**해럴드도 모름**) |
| 토벌·현재 | 해럴드가 꿰뚫은 「심장」= **마나핵**. 상실 후 레이의 주문력 = **S급 마법사** 수준. 모험가 등록·급수 **없음** |

## 여신교 연합회

| 항목 | 내용 |
|------|------|
| 지위 | MVP 시점 **주류 종교** |

## 칭-오그 왕국

| 항목 | 내용 |
|------|------|
| 위치 | **스페탈린** 대륙 |

## 대장간 의뢰 경로

| 경로 | 인게임 | 세계관 |
|------|--------|--------|
| **협회 단체 주문** | **상시 의뢰** | 협회에 맡김. **어느 대장간**에서 받을지 **복불복**. **즉시** 수령 · 상대적으로 **저렴** |
