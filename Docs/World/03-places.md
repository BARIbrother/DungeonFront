# 03 — 장소

> 상태: **초안** — 비전·대사·추후 기획에서 이식.  
> 던전 **개념**(생성·주인)은 [01-world.md](01-world.md).

## MVP (현재 플레이 공간)

| 항목 | 내용 |
|------|------|
| 대장간 이름 | **수제 강철** |
| 위치 | **스페탈린** 대륙 · **칭-오그** 왕국(**군주제**) · **모르즈** 마을 / **모르즈 평야**(마을이 있어서 붙은 평야명). 던전(**뒷산 동굴** / 공문 **모르즈 동굴**) 앞 / 입구 대장간 |
| 모르즈 마을 | 인구 **수백** · 어느 정도 큰 마을. 던전 낀 마을이라 **여행객** 많음. **수제 강철** 외 **다른 대장간**도 있음 |
| 상태 (오프닝) | 전 주인 은퇴 → 공실 등록 → 주인공이 물려받음 |
| 뒷산 동굴 | 크지 않은 입문 던전. **기믹 없음**. 통칭 **뒷산 동굴** · 공문서·공식 등록명 **모르즈 동굴**. 던전 주인: **철갑수**(종). 플레이어는 탐험하지 않음 (배경·고객 출처) |

## 추후 던전 (보류)

상세·기믹은 [../99-further_implementation.md](../99-further_implementation.md). 세계관 한 줄만:

| # | 이름 | 한 줄 |
|---|------|------|
| 1 | 뒷산 동굴 (공문: **모르즈 동굴**) | 입문, 기믹 없음. 주인: **철갑수**. 작아서 통칭은 뒷산 동굴 |
| 2 | 혹한의 설원 | 냉기·열원 |
| 3 | 슬라임 서식지 | 단일 원료 가공 |
| 4 | 깊이 잠든 황금향 | 황금룡 **스우마그**(토착 신 취급). 무력 과시 → **관람료**로 황금. 명성 없음·골드 중심(플레이) |
| 5 | 좋은 대장간? | 애매한 의뢰 |
| 6 | 태고의 땅 | 생물 공정 |
