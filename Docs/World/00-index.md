## 규칙

- **확정만** 본문에 적는다. 미정은 `[미정]` 또는 표의 빈칸으로 둔다.
- 대화에서 새로 정한 내용은 해당 파일에 바로 반영하고, 이 인덱스의 상태를 갱신한다.
- 플레이 룰(하루 구조, 골드·명성 수치 등)은 vision/core-loop에 두고, 여기에는 **세계 안에서 왜 그런지**만 적는다.
