# 01 — 세계 개요

> 상태: **주요 항목 채움** — 대화로 확정.

## 한 줄

마법과 몬스터, 모험이 가득한 세계 **판타지오**.

## 확정

| 항목 | 내용 |
|------|------|
| 세계명 | 판타지오 |
| 분위기 (플레이 톤) | 밝은 경영 시뮬 — 부담 없이 공장을 키워 가는 느낌 |
| 인기 직업 | 모험가 — 부와 명예에 이끌린 젊은이가 끊이지 않음 |
| 대장장이의 위치 | 모험가에게 무기·방어구·아이템을 납품하는 **조력자** |
| 두 세력의 관계 | **모험가 협회** ↔ **대장장이 협회**가 **상부상조** |
| 조직 명칭 | 둘 다 **협회** (연합 사용 안 함) |
| 용사 칭호 | 해럴드가 블레이메르 토벌 공로로 **시초**. 이후 지대 공헌자에게 수여. **현재 9명** (1대 해럴드 … **9대 플레켈 / Plekel** 등) |
| 시대·문명 | **비행기 발명 직전**의 산업혁명 수준. **마법 / 기계 혼재** |
| MVP 무대 | **스페탈린** 대륙 · **칭-오그** 왕국 · **모르즈** 평야 |
| 마법 | **아주 흔함**. 공장과 **긴밀히 연결**. 공장 동력은 **마력석**으로 공급. 마력을 쓰거나 부여하는 기계도 다수 |

## 던전

| 항목 | 내용 |
|------|------|
| 생성 | 세계 어딘가에서 **마력이 여러 요인으로 한 지점에 응집**. 모인 마력이 **임계점을 넘으면** 던전이 생성됨. 응집 요인은 **다양함** |
| 던전 주인 | 그 던전에 서식하는 생물종 중 **가장 강한 것**. 대부분 **한 종**을 가리킴 |
| 예외 | 드물게 **개체**나 **현상** 등을 주인으로 부르는 경우도 있음 |

> 개별 던전·지명은 [03-places.md](03-places.md). 플레이어는 던전을 탐험하지 않음 (배경·고객 출처).

## 용

| 항목 | 내용 |
|------|------|
| 지위 | **태고** 세계를 지배한 강대한 종 |
| 멸종 | 인류 등장 시점에는 대부분이 멸종 |
| 잔존 (인류 등장 이후 ~ 50년 전) | **3개체**만 생존 |
| 현재 (세간 인식) | 블레이메르 토벌 이후 **2체** (스우마그·트릴론) |
| 실제 | 블레이메르(레이)까지 포함하면 여전히 **3체** |

| 항목 | 내용 |
|------|------|
| 상태 | 생존 |

| 던전명 (모험가 협회) | **깊이 잠든 황금향** |
| 던전 주인 | 스우마그 (개체) |
