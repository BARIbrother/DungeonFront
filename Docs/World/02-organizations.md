### 필기 대사에서 언급된 제도 (세계관 힌트)

> 오프닝 개그로 나온 내용. **정본으로 쓸지** 대화에서 확정.

| 내용 | 비고 |
|------|------|
| 대장장이 협회 ↔ 모험가 협회는 **동등한 지위·발언권** | 힌트 |
| 소속 대장장이는 면허를 **항상** 보유 | 힌트 |
| 면허 **등급**(금/은 등)과 **갱신 주기** | 힌트 — 세부 `[미정]` |
| 협회는 생산 명령·영업 정지 등 강제 가능. 단 **납품 일정 변경**은 「모험가-대장간 연대 조례」로 강제성 없음 | 힌트 |
| 철 광석 **레벨**, 기계 레벨과의 관계 | 플레이 룰과 겹침 — 세계관 설명으로 쓸지 `[미정]` |
