# 02 — 조직·제도

## 확정

| 항목 | 내용 | 출처 |
|------|------|------|
| 공식 명칭 | **모험가 협회** · **대장장이 협회** (둘 다 협회) | 대화 확정 |
| 두 협회 관계 | **동등한 지위·발언권**. 세계관 **보편 상식** | 오프닝 필기 · 대화 |
| 대장장이 면허 | 대장간 운영에 **필수**. 협회 발급. 소속 대장장이는 면허를 **항시** 보유 | 오프닝 |
| 면허 등급 | **동 / 은 / 금** 3단계. 시험 통과 **칭호** — 관심 없으면 **동**이어도 실력 뛰어날 수 있음 | 대화 확정 |
| 마하르·양성 | 3대 용사 **마하르** **현역**. 대장장이 양성은 **협회와 연결** | 대화 확정 |
| 면허 갱신 | **금**: **3년** 주기. **은 이하**(은·동): **5년** 주기 | 오프닝 필기 |
| 협회 강제권 | 특정 물품 **생산·생산 중단**, 대장간 **영업 정지** 등은 강제 가능. 단 **납품 일정 변경**은 「**모험가-대장간 연대 조례**」 **2조 1항**으로 **강제성 없음** | 오프닝 필기 |
| 실기 시험 | 실제 대장간 운영으로 면허 실기를 볼 수 있음 | 오프닝 |
| 필기 시험 | 별도 기수. **시험관 재량**으로 실기 선진행 가능(특례) | 오프닝 · 대화 |
| 실기 선진행 특례 | 필기에 관심 없는 **천재**가 왕왕 있음. 무면허로 두기 아까워 협회가 **시험관 재량**으로 실기 먼저 치게 함. 이브가 주인공에게 준 것도 이 제도 | 대화 확정 |
| 이브의 소속 | 대장장이 협회 **유지 및 관리 지부** · **4급 감사관**. **말단** · 능력 있어 **촉망받는 신입** | 오프닝 · 대화 |
| MVP 목표 | 스토리 엔딩 = **대장장이 면허** 취득 (**동**부터) | 대화 확정 |
| 화폐 | **골드**. 5대 용사 **하와즈미**가 제정. 관련: **판타지오 중앙 은행**(하와즈미 명예회장) | 대화 확정 |
| 명성 (게임 재화) | **게임 UI에만 존재**. 세계관상 협회가 **의뢰 실적**으로 설비 허용을 판단 | 대화 확정 |
| 모험가 급수 | **F급 ~ S급**. 용사와는 별개. **일반 마법사**도 모험가 협회 소속. 상세: [lore.md](lore.md) | 대화 확정 |
| 의뢰 경로 | **둘**. ① 협회 **단체 주문**(인게임 **상시 의뢰**) ② **직접 의뢰·납품**(인게임 **일반 의뢰**). 상세: [lore.md](lore.md) | 대화 확정 |
| 무면허·실기 중 | 실기 시험 **진행 중**이면 협회 단체 주문 등 수주 **허용**(주인공 오프닝 케이스) | 대화 확정 |

## 철 광석 · 기계 (오프닝 필기 = 정본)

| 항목 | 내용 |
|------|------|
| 제작 순서 | **철 광맥 → 용광로 → 기타 제작 장치** |
| 레벨·기계 | **모든 기계**가 **모든 레벨** 철 광석을 재련 가능. (높은 레벨은 속도만 끔찍하게 느림). 「높은 레벨 광석엔 높은 레벨 기계 필수」는 **아님** |
| 가치 | 철 광석 레벨이 **1 오를 때마다 가치 10배** |
| 기계 재료 | 모든 기계의 제작 재료로 **철 광석에서 파생된 생산품**이 필요 |
