# Q017 — 보강된 갑옷

- 종류: 서브
- 선행 퀘스트: Q002
- 기한: 2일

## 제목

보강된 갑옷

## 의뢰인 이름

모험가 플린트

## 내용

저번 탐사에서 아끼는 흉갑이 상해 버렸지 뭐야, 이참에 마법 공격에 대비한 갑옷도 구비해 둬야겠어. 마나강 강화 흉갑을 만들어 줄 수 있을까? 방어 마법도 인챈트해서 부탁해.

## 요구 아이템 목록

- `manasteel_chestplate` (마나강 흉갑) ×1 · 인챈트: 불 (Fire)
  - 변환: manasteel_chestplate_fire_proof → manasteel_chestplate + Fire

## 보상 목록

- `gold` (골드) ×20
- `fame` (명성) ×20
