# Q012 — 튼튼한 갑옷

- 종류: 서브
- 선행 퀘스트: Q001
- 기한: 2일

## 제목

튼튼한 갑옷

## 의뢰인 이름

모험가 플린트

## 내용

저번 탐사에서 아끼는 투구가 상해 버렸어. 이참에 갑옷을 전부 새로 맞출까 해. 반짝반짝한 철 갑옷 세트로 줘!

## 요구 아이템 목록

- `iron_helmet` (철 투구) ×1
- `iron_chestplate` (철 흉갑) ×1
- `iron_leggings` (철 각반) ×1
- `iron_boots` (철 부츠) ×1

## 보상 목록

- `gold` (골드) ×150
- `fame` (명성) ×150
