# Q001 — 첫 번째 시험

- 종류: 메인
- 선행 퀘스트: 없음 (시작 열)
- 기한: 1일

## 제목

첫 번째 시험

## 의뢰인 이름

감사관 이브

## 내용

첫 번째 과제는 대장장이의 기본 중의 기본, 철을 다루는 것입니다. 당신이 이 정도 과제도 수행하지 못 한다면 합격은 물 건너간 일이라 봐야겠죠. 기본 3종을 10개씩 납품해 보시죠.

## 요구 아이템 목록

- `iron_ore` (철광석) ×10
- `iron_bar` (철 주괴) ×10
  - 변환: iron_ingot → iron_bar (철 주괴)
- `iron_plate` (철 판) ×10

## 보상 목록

- `gold` (골드) ×50
- `fame` (명성) ×50
