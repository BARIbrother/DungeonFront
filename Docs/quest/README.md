# Questline

원본: `questline.json` (questline-editor export).

아이템 코드 변환 전체표(원본 한글 포함): [`item-code-mapping.md`](./item-code-mapping.md)

폴더 구조: 메인 퀘스트 id별로 묶음. 각 폴더에 메인 + 같은 열의 사이드 퀘스트 md를 둔다.

Unity SO: `Assets/Quest/{메인id}/Q###.asset` (동일 묶음).  
데이터베이스: `Assets/Resources/Data/QuestDatabase.asset`  
재생성: Unity 메뉴 `DungeonFront/Generate Quest Assets From Questline`  
개발자 모드(F8): [`Docs/dev-mode.md`](../dev-mode.md)

## 진행 규칙

- **메인** (y < 320): 왼쪽→오른쪽. 바로 왼쪽 메인 클리어 후 해금.
- **서브**: 같은 세로 열의 메인이 해금될 때 **함께** 해금.
- 보상: 요구 품목 제작 가치(기본재화 1, 마나 100=1, 조합 +10% 버림)로 골드=명성 동일 수치.
