# Q031 — 겉모습

- 종류: 서브
- 선행 퀘스트: Q010
- 기한: 1일

## 제목

겉모습

## 의뢰인 이름

대장장이 클로

## 내용

어이, 신참. 혹시나 노파심에 말하는 건데, 흑마법석으로 '흑마법석 검'같은 걸 만들 생각은 추호도 하지 마. 그런 건 그저 장식용일 뿐이야. 흑마법석은 자체 내구도가 너무 약해 단일 재료로 검을 만들면 쉽게 부러져 버린다네. 
장점이라곤 칠흑같은 빛, 마법석 검과는 결이 다른 메탈릭한 금속음, 검날의 중간 중간 보이는 새빨간 마력선밖에 없다네.
...말하니까 하나 갖고 싶어졌네. 재료만 만들어 줘.
