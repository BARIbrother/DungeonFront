# Q006 — 네 번째 시험

- 종류: 메인
- 선행 퀘스트: Q010
- 기한: 2일

## 제목

네 번째 시험

## 의뢰인 이름

감사관 이브

## 내용

높은 레벨의 광물을 다룰 수 있게 된다는 건 그만큼 정밀하고 섬세한 실력을 갖춰야 한다는 뜻입니다. 마하르 님의 격언, '큰 망치에는 큰 책임이 따른다'처럼요.

## 요구 아이템 목록

- `iron_sword` (철 검) ×10
- `darksteel_sword` (흑강 검) ×10
- `brightsteel_sword` (백강 검) ×10

## 보상 목록
