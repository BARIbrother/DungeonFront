# Q030 — 흑과 백은 어떻게 합쳐지는가

- 종류: 서브
- 선행 퀘스트: Q010
- 기한: 2일

## 제목

흑과 백은 어떻게 합쳐지는가

## 의뢰인 이름

마법사 헌츠

## 내용

흑마법, 백마법 코어도 똑같네. 왜 철 주괴에 마력석 결정, 칠흑석 주괴를 합금해야만 만들 수 있는 거지? 마력 코어에 칠흑석 주괴를 조합하면 안 되는 건가? 제작자가 레시피 두 개를 만들기 귀찮았다고 생각할 수도 있지.
그것도 맞네.

## 요구 아이템 목록

- `dark_magic_staff` (흑마술 지팡이) ×1
  - 변환: dark_mana_wand → dark_magic_staff
- `light_magic_staff` (백마술 지팡이) ×1
  - 변환: bright_mana_wand → light_magic_staff

## 보상 목록

- `gold` (골드) ×40
- `fame` (명성) ×40
