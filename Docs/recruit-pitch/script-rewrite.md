# PPT 대사 교체표

현재 PPT 10장 기준. 오른쪽만 채운다. 비워 두면 기존 문장을 유지한다. `삭제`라 적으면 삭제한다.  
`화면` = 슬라이드에 보이는 글. `노트` = 발표할 때 읽는 글.

전반(1–4, 8) = 이 게임이 무엇인지. 후반(5–7, 9–10) = 새 던전 컨텐츠.
