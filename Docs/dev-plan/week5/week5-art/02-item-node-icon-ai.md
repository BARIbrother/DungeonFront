## 1. 이 작업물

아래 **Art 담당 44종** 아이템 아이콘을 AI로 생성·선정·전달한다.

**크기**: **16×16** 픽셀  
**검수**: `Assets/Art/Items/_preview/` (×16 Nearest)  
**규칙**: `Docs/art/item-icon-rules.md`  
**구간**: `>>>나무` · `>>>철` · `>>>칠흑석` · `>>>순백석` · `>>>진강`

## 2. 장비·소재 컨셉

| 계열 | 컨셉 |
|------|------|
| **흑강** | 철 장비·소재에 **검은 판을 둘러** 강화한 느낌 |
| **백강** | 철 장비·소재에 **흰 판을 둘러** 강화한 느낌 |
| **진강** | **흑과 백이 균형** 있게 붙은 느낌 |

철 기본형(흉갑·투구·각반·부츠·검·망치 등)을 베이스로 두고, 위 규칙으로 파생 아이콘을 구분한다.  
주괴·판·막대기도 같은 색·재질 언어를 맞춘다.
