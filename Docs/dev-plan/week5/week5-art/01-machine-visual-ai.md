# 기계 비주얼 1차 (AI)

**역할**: Art · **Week**: 5 · **Issue**: 01  
**선행**: Week 4 기계 비주얼 러프 · 회의 선택안

## 1. 이 작업물

MVP 기계·벨트·출력기 **1차 스프라이트**를 AI로 뽑아 선정·정리·전달한다. 수작업 최종 픽셀 아님.

**경로**: `Assets/Art/Machines/` (팀 관례 경로)

## 2. 해상도 규칙

**그리드 footprint × 32픽셀** (가로·세로 각각).

| footprint | 픽셀 |
|-----------|------|
| 1×1 | 32×32 |
| 1×2 | 32×64 |
| 2×2 | 64×64 |

예: 2×2 기계 → **64×64** 픽셀.
