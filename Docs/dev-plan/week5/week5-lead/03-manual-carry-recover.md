# 인벤 배치·출력 즉시 회수

**역할**: Lead · **Week**: 5 · **Issue**: 03  
**선행**: Week 3~4 수작업·물류 골격 · `PlayerInventory` · 기계 UI(`MachineRecipeUI` 등)

## 1. 이 작업물

**기계 UI를 열면** 플레이어 인벤토리와 기계 포트 사이에서 **재료를 넣고 뺄 수 있게** 한다.  
플레이어 인벤토리는 **글로벌 인벤토리**로 쓴다. 월드 칸·포트 간 **들기/놓기는 없다**.  
벨트·출력기 우선순위 재설계·기계 정보 패널 고도화는 범위 밖.

**코드**: `Assets/Scripts/Machine/` (기계 UI), `Assets/Scripts/Player/PlayerInventory.cs`, Factory 씬

## 2. 작업 내용

- 기계 클릭 → UI에서 인벤 ↔ 입력/출력 포트 넣고 빼기 (인벤 클릭=입력에 1개, 포트 클릭=해당 스택 전량 인벤 회수)
- 점유·수량 부족·배치 실패 시 크래시 없이 거부
- 벨트·창고(즉시 인벤 이관)는 이 UI 비대상
- 발견되는 배치·I/O 회귀는 서브로 함께 수정

## 3. 완료 기준

- [ ] 기계 UI에서 인벤 → 포트 투입 가능
- [ ] 기계 UI에서 포트 → 인벤 회수 가능
- [ ] 잘못된 조작 시 크래시 없이 거부
- [ ] 튜토 철 체인에서 인벤 투입/회수로 막히지 않음
- [ ] Console Error 0 (문서화된 경고만)
