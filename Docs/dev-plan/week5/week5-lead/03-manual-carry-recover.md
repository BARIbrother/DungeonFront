# 수동 운반·출력 즉시 회수

**역할**: Lead · **Week**: 5 · **Issue**: 03  
**선행**: Week 3~4 수작업·물류 골격

## 1. 이 작업물

생산 중 **플레이어 수동 운반**과 **출력 포트 즉시 인벤 회수**를 본구현한다.  
벨트·출력기 우선순위 재설계·기계 정보 패널 고도화는 범위 밖.

**코드**: `Assets/Scripts/Machine/`, `Assets/Scripts/Player/`, Factory 씬

## 2. 작업 내용

- 들기/놓기(또는 프로젝트 확정 조작)로 칸·포트 간 아이템 운반
- 출력 포트만 클릭/키로 즉시 인벤 회수
- 점유·드롭 실패 시 크래시 없이 거부
- 발견되는 배치·I/O 회귀는 서브로 함께 수정

## 3. 완료 기준

- [ ] 생산 중 수동 운반으로 아이템 이동 가능
- [ ] 출력 포트 즉시 회수가 인벤에 반영
- [ ] 잘못된 조작 시 크래시 없이 거부
- [ ] 튜토 철 체인에서 운반/회수로 막히지 않음
- [ ] Console Error 0 (문서화된 경고만)
