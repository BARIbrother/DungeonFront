# 맵 설계

**역할**: Lead · **Week**: 5 · **Issue**: 05  
**선행**: Week 4 구역·맵/노드

## 1. 이 작업물

Factory 맵의 **2차원 구역 해금**과 **자원 노드(상대 위치·활성)** 를 정본으로 잠그고 씬에 반영한다.  
가로·세로 칸 수·월드 좌표는 피드백으로 바뀔 수 있으므로, **열리는 구역의 상대 위치**를 먼저 확정한 뒤 상세를 채운다.

**대상**: Factory 맵 · 구역 격자 · MVP 자원 노드 4종(철·마력석·칠흑석·순백석) 및 lv

## 2. 축·구역 모델

| 축 | 의미 |
|----|------|
| **x →** | 자원 라인 (철 → 마력석 → 칠흑석·순백석) |
| **y ↑** | 레벨 (lv1 → lv2 → lv3) |

- 해금 단위는 **정수 구역** `(x, y)` 뿐이다. `x1–x2`, `y1–y2` 같은 표기는 **두 구역이 맞닿는 경계선**이지, 별도 구역이 아니다.
- 구역 크기 초안: **한 변 16칸** (피드백으로 가변). 전체 그리드 **48×64**. 상세 좌표보다 **상대 배치**가 우선 정본이다.
- 확장은 격자의 **인접 칸**(가로 또는 세로 한 칸)으로만. 대각선으로 건너뛰지 않는다.
- 물류는 **글로벌 창고로 input을 넣는 기계**를 전제로 한다. 맵에 메인버스형 동선을 요구하지 않는다.

### 상대 격자

```
y4     lv3
y3     lv2
       ← y2–y3 경계 (노드 슬롯 가능)
y2     lv1  (노드 수 > y1)
       ← y1–y2 경계 (노드 슬롯 가능)
y1     lv1  (한 변 16칸, 혼합 배치)
     x1    x2    x3
      │     │
   x1–x2  x2–x3  경계 (노드 슬롯 가능)
```

| 구역 x | 구역에 두는 자원 테마 |
|--------|----------------------|
| `x1` | 철 |
| `x2` | 마력석 |
| `x3` | 칠흑석·순백석 |

| 구역 y | 레벨 | 노드 (구역당) |
|--------|------|----------------|
| `y1` | lv1 | 5 (칠흑·순백 구역은 3+3) |
| `y2` | lv1 | 10 (칠흑·순백 구역은 5+5) |
| `y3` | lv2 | 5 (칠흑·순백 구역은 3+3) — 티어당 y행 1개라 `y1`과 동일 초안 |
| `y4` | lv3 | 5 (칠흑·순백 구역은 3+3) — 동상 |

## 3. 자원 해금 순서 (노드 활성 플래그)

맵에 슬롯을 미리 두더라도, **채굴 가능 여부는 활성 플래그**로 연다.  
MVP에서 열리는 자원은 네 가지: **철 · 마력석 · 칠흑석 · 순백석**.

순서:

1. 철  
2. 마력석  
3. 칠흑석 · 순백석  
4. 철 lv2  
5. 마력석 · 칠흑석 · 순백석 lv2  
6. 철 lv3  
7. 마력석 · 칠흑석 · 순백석 lv3  

같은 스텝에 묶인 자원(예: 칠흑석·순백석, lv2/lv3의 마·칠·순)은 **한 번에** 연다.

## 4. 노드 배치

- 구역 **내부**: 혼합 배치. 소수 노드로 처리량을 감당한다. 같은 lv1이라도 **`y2` 행은 `y1`보다 노드를 더 넣는다**.
- 구역당 노드 수 초안: **`y1` = 5**, **`y2` = 10** (철·마력석 등 단일 테마 구역).
- **칠흑석·순백석을 같이 넣는 구역/경계**는 두 자원 **동일 개수**. 목표 총수가 홀수면 **1개 추가**해 짝수로 만든 뒤 반반 (예: 5 → 6 = 3+3, 10 → 10 = 5+5).
- 구역 **경계**: 띄엄띄엄 배치. 해금 전에는 **비활성**.  
  - 비활성일 때: “이 방향으로 더 열면 이 자원/티어” 힌트.  
  - 활성 후: 내부 노드와 같이 **실제 채굴에 기여** (전체 노드 수가 적어 경계 분량도 의미 있음).
- 경계는 구역이 두 개이므로, 활성 후보는 **더 높은 쪽 구역**(오른쪽 x / 위쪽 y)이 열린 뒤 + 해당 자원 플래그로 처리한다.

### 슬롯 테마 (상대 위치)

| 위치 | 두는 자원 (테마) |
|------|------------------|
| `x1` 내부 | 철 |
| `x1–x2` 경계 | 철 · 마력석 |
| `x2` 내부 | 마력석 |
| `x2–x3` 경계 | 칠흑석 · 순백석 |
| `x3` 내부 | 칠흑석 · 순백석 |
| `y1` 일대 | lv1 · 구역당 5 (칠흑·순백 구역은 6 = 3+3) |
| `y2` 일대 | lv1 · 구역당 10 (칠흑·순백 구역은 5+5) |
| `y1–y2` 경계 | lv 방향 힌트·기여 슬롯 |
| `y2–y3` 경계 · `y3` | lv2 |
| `y4` | lv3 |

### 노드 좌표 초안 (자원 × 레벨)

좌표계:

- 원점 `(0,0)` = 구역 `(1,1)` 남서 코너 타일  
- `+X` = 동쪽(자원 라인), `+Y` = 북쪽(레벨)  
- 구역 `(zx, zy)` 범위 = `[ (zx-1)×16 .. zx×16−1 ]` × `[ (zy-1)×16 .. zy×16−1 ]`

생성:

- 시드 `20260801` (16칸 재생성)  
- 구역 중앙 ~38% 기피 · 타 구역 경계 2칸 감쇠 · 최소 거리 3 · 약한 클러스터  
- lv1 = `y1`+`y2` 합산, lv2 = `y3`, lv3 = `y4`
