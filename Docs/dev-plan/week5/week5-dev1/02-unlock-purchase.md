# 해금 후 구매 연동

**역할**: Dev1 · **Week**: 5 · **Issue**: 02  
**선행**: Issue 01 명성 해금 UI · Week 4 경제 골격

## 1. 이 작업물

명성으로 해금된 기계·레시피를 **골드로 구매/제작**할 수 있게 연결한다.

**코드**: `Assets/Scripts/GameFlow/`, 인벤·상점/제작 UI

## 2. 작업 내용

- 미해금 대상은 구매/제작 불가
- 해금 후 골드 차감·인벤 지급 (또는 제작 플로우)
- 골드 부족 시 거부·안내
- 세이브에 해금·보유 상태가 남는지 회귀

## 3. 완료 기준

- [ ] 해금 전에 구매/제작 불가
- [ ] 해금 후 골드 차감·지급 정상
- [ ] 부족 시 크래시 없이 거부
- [ ] 해금·보유가 세이브 round-trip
- [ ] Console Error 0 (문서화된 경고만)
