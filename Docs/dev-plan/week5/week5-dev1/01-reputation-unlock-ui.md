# 명성 해금 UI

**역할**: Dev1 · **Week**: 5 · **Issue**: 01  
**선행**: Lead `04-reputation-unlock-plan` 정본

## 1. 이 작업물

Lead 명성 해금 표를 UI로 구현한다. 트리/목록·조건 표시·수동 해금 확정.

**코드**: `Assets/Scripts/GameFlow/`

## 2. 작업 내용

- 명성 threshold·해금 대상 표시
- 미달/충족/이미 해금 상태
- 노드(또는 목록 항목) 클릭 → 확인 → 해금
- 선행 해금 규칙이 표에 있으면 반영

## 3. 완료 기준

- [ ] Lead 표의 구간·대상이 UI에 표시됨
- [ ] 명성 미달 시 해금 불가
- [ ] 확인 후 해금 상태가 세션에 반영
- [ ] 이미 해금된 항목 재해금 없음
- [ ] Console Error 0 (문서화된 경고만)
