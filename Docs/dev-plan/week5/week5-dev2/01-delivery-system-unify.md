# 납품 시스템 통합

**역할**: Dev2 · **Week**: 5 · **Issue**: 01  
**선행**: Week 4 결산·의뢰·상시 골격

## 1. 이 작업물

결산(또는 납품 UI) 안에 **일반·상시** 납품을 한 흐름으로 넣는다.  
아래 하위는 이 Issue 한 건의 범위다.

**코드**: `Assets/Scripts/Quest/`, 결산·납품 UI

## 2. 하위 범위

### 2-1. 일반 납품

- 유한 수요 · 납기 · 부분 납품 불가 · 보상(골드·명성)
- 필요 시 `stockTarget` (목표 도달 시 수요 종료)

### 2-2. 상시 납품

- 미수락 · 무기한 · 배수 n 제출 · 납품 후에도 유지
- 슬라이더(또는 동등 UI)로 n 선택

### 2-3. 타입/규칙

- `questType`: story / normal / perpetual
- `isMandatory`에 따른 필수(스토리) 분기 유지
- 스토리 필수는 기존 필수 납품·게임오버 규칙과 충돌 없이 공존

## 3. 완료 기준

- [ ] 한 납품 UI/흐름에서 일반·상시 구분 처리
- [ ] 일반: 유한·납기·부분 불가·보상
- [ ] 상시: 미수락·배수 n·유지
- [ ] questType·isMandatory 분기가 맞음
- [ ] 멀티데이·미납·게임오버 회귀 통과
