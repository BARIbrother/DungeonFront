# 상호작용 범위 제한 버전

**역할**: Lead · **Week**: 7 · **Issue**: 01  
**선행**: Week 6 통합 빌드

## 1. 이 작업물

플레이어 **상호작용이 제한된 범위** 안에서만 동작하는 버전을 만든다.

## 2. 작업 내용

- 상세(대상·범위·버전 형태)는 요구 표가 채워진 뒤 본문에 반영한다
- 채워진 표 기준으로 범위 제한 버전을 구현·검증한다

## 3. 완료 기준

- [ ] 상호작용 범위가 제한된 버전이 존재한다
- [ ] 요구 표에 정한 범위 밖 상호작용이 되지 않는다
- [ ] 요구 표에 정한 범위 안 상호작용이 된다
- [ ] Console Error 0 (문서화된 경고만)
