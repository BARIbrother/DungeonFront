# 테스트 플레이·밸런스 피드백

**역할**: Dev1 · **Week**: 6 · **Issue**: 01  
**선행**: Week 5 통합 가능 빌드(또는 Lead 통합본)

## 1. 이 작업물

게임을 **직접 플레이**하며 밸런스 관련 피드백을 남긴다.  
코드 본구현·수치 확정 lock은 범위 밖. 발견한 이슈를 기록해 전달한다.

## 2. 작업 내용

- 튜토~엔딩(또는 핵심 구간) 테스트 플레이
- 너무 쉽/어렵·시간·보상·해금 리듬 등 밸런스 이슈 기록
- 재현 가능한 경우 상황(일차·페이즈·행동)을 함께 적음
- 크래시·진행 불가는 즉시 별도 보고

## 3. 완료 기준

- [ ] 핵심 구간 이상 테스트 플레이 수행
- [ ] 밸런스 피드백이 항목별로 정리되어 제출됨
- [ ] 재현 상황(가능 시)이 피드백에 포함됨
- [ ] 진행 불가·크래시는 별도 보고됨
