# 산출물 통합

**역할**: Lead · **Week**: 6 · **Issue**: 01  
**선행**: Week 5 각 역할 산출물

## 1. 이 작업물

Dev1·Dev2·Art가 만든 것을 **하나의 플레이 가능 빌드**로 합친다.  
신규 기능 본구현은 하지 않는다. 머지 충돌·깨진 참조·크래시만 막아 통합 상태를 유지한다.

## 2. 작업 내용

- Dev1·Dev2·Art 브랜치(또는 PR) 머지
- 충돌·누락 참조·씬/프리팹 깨짐 해소
- 통합 후 튜토~엔딩(또는 핵심 구간) 1회 스모크
- 통합 중 발견 회귀는 함께 수정

## 3. 완료 기준

- [ ] Dev1·Dev2·Art 산출물이 한 빌드에 포함
- [ ] 머지 충돌·깨진 참조 없음
- [ ] 통합 빌드에서 튜토~엔딩(또는 핵심 구간) 1회 플레이 가능
- [ ] Console Error 0 (문서화된 경고만)
