# 아이템 아이콘 생성 규칙

Week5 Art 아이템 아이콘 작업에서 확정한 **범용 규칙**.  
이후 철·흑강·백강·진강·나무 등 모든 아이템 아이콘에 적용한다.

에이전트용 요약: `.cursor/rules/item-icon-art.mdc`

---

## 1. 파일·규격

| 항목 | 규칙 |
|------|------|
| 경로 | `Assets/Art/Items/` |
| 원본 크기 | **16×16** PNG, RGBA, 투명 배경 |
| 파일명 | `{itemId}_icon.png` (예: `iron_helmet_icon.png`) |
| 예외 | itemId `iron`(철 주괴) → `iron_ingot_icon.png` |
| 매칭표 | `Assets/Art/Items/item_icon_map.txt` (표시명 · itemId · 파일명) |
| meta | `*.meta`는 만들지 않는다 (Unity가 생성) |

### 검수용 확대본 (필수)

원본 16×16은 검수 시 작으므로, 아이콘을 **만들거나 수정할 때마다** 같이 갱신한다.

| 항목 | 규칙 |
|------|------|
| 경로 | `Assets/Art/Items/_preview/` |
| 방식 | Nearest Neighbor 확대 (**×16** → 256×256) |
| 개별 | `_preview/{같은파일명}` |
| 시트 | `_preview/_sheet.png` — **카테고리별 행**, 배경 **연두색** `(200,230,160)` |
| 주괴 | **5×5×10 직육면체**(긴 축=앞뒤), 정면에서 **위로 30°·오른쪽 30°**, 3면(윗·앞·옆) |
| 용도 | 사람·에이전트 검수용. **게임에 import하지 않음** |

---

## 2. 화풍

- 하드 픽셀 (블러·안티앨리어싱 없음)
- 아이템당 제한된 팔레트 (대략 4~7색 + 외곽선)
- 외곽선: 진한 남회색/검정에 가까운 1px
- 같은 소재 계열은 **색·재질 언어를 통일**

---

## 3. 실루엣·구분 (최우선)

**실루엣만 봐도 종류를 알 수 있어야** 한다. 명암만 다르고 모양 비슷한 것은 금지.

| 종류 | 실루엣 가이드 |
|------|----------------|
| 광석 | 둥근·불규칙 덩어리 |
| 주괴 | **5×5×10 직육면체**(긴 축=앞뒤), 정면↑30°·오른쪽30°, 3면 |
| 판 | **꼭짓점이 날카로운** 넓고 얇은 평행사변형·다이아 (비스듬히 위) |
| 막대 | 가느다란 대각선 로드 |
| 원목 | 가로 통나무 + 단면 나이테 |

가공품(주괴·판)은 광석과 **둥근 덩어리로 닮지 않게**.

---

## 4. 조명

| 대상 | 규칙 |
|------|------|
| **장비** (흉갑·투구·각반·부츠·검·망치 등) | **정면 조명**: 앞면 중앙이 밝고, 좌·우 가장자리가 어둡다. 왼쪽만 밝은 획일 광원 **금지** |
| **소재·자원** (원목·광석·주괴·판·막대 등) | top-left 하이라이트 허용 |

---

## 5. 장비 디테일 (철 기본형 → 파생 동일 구조)

철 장비를 베이스로 흑강·백강·진강은 판 덧댐·색만 바꾼다.

| 부위 | 규칙 |
|------|------|
| 투구 | 눈 구멍(바이저) **크게** |
| 흉갑 | 어깨 패드 **크게** |
| 각반 | 다리 **굵고**, 사이 간격 **좁게/붙여서** |
| 부츠 | 발목(샤프트) **굵게**, 한 쌍은 간격 유지 |

### 계열 파생 (기획 컨셉)

| 계열 | 컨셉 |
|------|------|
| 흑강 (`darksteel`) | 철 장비와 **同형** + 끄트머리 **뾰족 장식**. 색은 **검정+보라 명암만** (흰색·은색 하이라이트 금지) |
| 백강 (`brightsteel`) | 철 장비와 **同형** + **흰 판** 덧댐. 장비는 **중간 선(심)** 으로 단단·뭉툭한 느낌 (흑강처럼 뾰족 장식 쓰지 않음) |
| 진강 (`greysteel`) | **흰 메탈 + 흑강과 同계열 어두운 보라** 5:5 메탈릭. **전용 실루엣**(투구=갓/첨탑, 흉갑=X교차, 각반=스커트+짧은 다리, 부츠=바깥 사밧톤). **정면 조명** |

---

## 6. 작업 체크리스트

아이콘 추가/수정 시:

1. 16×16 원본 저장 (`Assets/Art/Items/`)
2. `_preview` 개별 확대본 + `_sheet.png` 갱신
3. `item_icon_map.txt` 행 추가/수정
4. 실루엣 구분·조명(장비=정면) 규칙 만족 여부 확인
