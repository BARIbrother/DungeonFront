# GDC 기능 수동 테스트 안내

## 준비

1. Unity에서 `Assets/Scenes/Factory.unity`를 연다.
2. Console을 Clear한다.
3. Play를 누른다.
4. 임시 패널은 `F10`으로 연다.

아이템 아이콘은 이번 작업 범위에서 보류했다.

## 1. 대사 UI

1. 새 게임 시작 직후 오프닝 대사가 나타나는지 확인한다.
2. 화자·본문·다음/닫기 버튼이 보이는지 확인한다.
3. 대사 중 `Time.timeScale`이 0이고 캐릭터·생산이 멈추는지 확인한다.
4. Space/Enter 또는 다음 버튼으로 끝까지 진행한다.
5. 오프닝 뒤 첫 의뢰 안내가 이어지는지 확인한다.
6. 누락되면 F10 → `오프닝 대사 001E00001`로 독립 시험한다.

## 2. 일시정지·설정

1. 대사와 튜토리얼을 닫는다.
2. ESC를 눌러 일시정지 메뉴를 연다.
3. 화면이 멈추고 계속하기로 복구되는지 확인한다.
4. 해상도·전체 화면·음량을 변경한다.
5. 메뉴를 다시 열었을 때 값이 유지되는지 확인한다.

## 3. 퀘스트 카드 수량

1. 준비 단계에서 의뢰 하나를 수락한다.
2. 결산으로 이동하기 전 카드 요구 항목이 `보유/요구`로 표시되는지 본다.
3. F10 → `첫 수락 의뢰의 요구 재료 지급`을 누른다.
4. 수량이 즉시 증가하고 충분한 항목이 초록색으로 바뀌는지 확인한다.
5. Settlement에서 납품 버튼이 활성화되는지 확인한다.

## 4. 하루 흐름

1. Prepare에서 의뢰를 수락한다.
2. 기계를 배치하고 생산 시작을 누른다.
3. 생산 종료 요약을 확인한다.
4. Settlement에서 전량 납품한다. 부분 납품은 되면 안 된다.
5. 다음 날 버튼으로 Day가 증가하고 Prepare로 돌아오는지 확인한다.

빠른 확인은 F10의 페이즈 이동 버튼을 순서대로 사용한다.

## 5. 상시 의뢰

1. Settlement로 이동한다.
2. 오른쪽 위 `상시 의뢰` 버튼을 누른다.
3. 좌우 버튼으로 의뢰를 변경한다.
4. 보유량·제출량·가능 최대 배수가 표시되는지 확인한다.
5. 슬라이더로 배수를 정하고 납품한다.
6. 재고가 정확히 배수만큼 줄고 보상이 배수만큼 증가하는지 확인한다.

## 6. 저장·불러오기

1. 아이템·골드·명성·수락 의뢰 상태를 기억한다.
2. ESC → 저장하기 또는 F10 → 슬롯 0 저장을 누른다.
3. 값을 변경한다.
4. 불러오기를 눌러 날짜·페이즈·골드·명성·아이템·의뢰가 복원되는지 확인한다.

현재 저장 범위에 월드 기계 배치와 생산 중 WIP는 포함되지 않는다.

## 7. 게임오버

1. F10 → `게임오버 화면 강제 표시`를 누른다.
2. 게임오버 메시지와 새 게임 시작 버튼이 나타나는지 확인한다.
3. 새 게임 시작 후 Day 1 Prepare로 돌아오는지 확인한다.

## 임시 패널 삭제

테스트가 끝나면 `Assets/Scripts/Temporary` 폴더 전체를 삭제한다. 다른 기능은 이 폴더에 의존하지 않는다.
